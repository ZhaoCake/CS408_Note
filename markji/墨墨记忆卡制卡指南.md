## 一、基本语法结构

普通文字直接输入，无需标签。需要语法时使用以下结构：

```text
[名称#参数1,参数2#内容]
```

**核心规则：**

1. 标签和参数**区分大小写**，必须使用规定形式：`T`、`P`、`F`、`Choice`、`Pic`、`Audio`、`Card`、`E` 等
2. `#` 分隔名称、参数和内容；**没有参数时也必须保留两个 `#`**（如 `[E##x+y]`、`[Choice##...]`）
3. 多个参数用英文逗号 `,` 分隔，标签名、参数和分隔符之间**不加空格**
4. 每个语法必须有未被转义的 `]` 结尾
5. 普通换行产生新段落；**块级语法必须从一行开头开始**
6. 除明确允许的位置外，不要嵌套语法
7. 显示普通中括号需转义：`\[` 和 `\]`
8. 不要依赖错误语法被自动修复，无法确认时使用纯文本

## 二、行内语法

### 1. 文字样式 `[T#参数#文字]`

| 参数 | 效果 | 示例 |
|---|---|---|
| `B` | 加粗 | `[T#B#重点]` |
| `I` | 斜体 | `[T#I#术语]` |
| `U` | 下划线 | `[T#U#关键词]` |
| `!rrggbb` | 文字颜色 | `[T#!e53935#红色文字]` |
| `!!rrggbb` | 背景颜色 | `[T#!!fff59d#高亮文字]` |
| `up` | 上标 | `x[T#up#2]` |
| `down` | 下标 | `H[T#down#2]O` |
| `link/"网址"` | 超链接 | `[T#link/"https://markji.com"#访问网站]` |

**约束**：颜色为 6 位小写十六进制（不带 `#`）；`up`/`down` 不可同用；样式内容中不可再放其他语法。

### 2. 挖空 `[F#编号#内容]`

```text
TCP 是面向[F#1#字节流]的协议，UDP 是面向[F#2#报文]的协议。
```

- 编号为从 `1` 开始的正整数，相同编号属同一组
- 不可省略编号，不可用 `0`、负数、小数或文字编号
- 挖空内容中**不可嵌套其他语法**

### 3. 音频 `[Audio#ID/音频ID#显示文字]`

参数：`ID/音频ID`、`M`（手动播放）、`A`（自动播放）、`D`（跟随用户设置）

- `M` 与 `A` 不可同用；需要自动播放时可省略 `A`
- 显示文字可为空，但必须保留第二个 `#`
- **只使用真实已有的音频 ID，不得编造**

### 4. 卡片引用 `[Card#ID/卡片ID#显示文字]`

多张卡片用连字符分隔：`[Card#ID/abc123-def456#查看相关卡片]`

- 只使用真实已有的卡片 ID；重复 ID 需去重
- 显示文字中不可嵌套语法

## 三、块级语法（必须从新一行的第一个字符开始）

### 1. 段落样式 `[P#参数#内容]`

| 参数 | 效果 |
|---|---|
| `H1` | 标题（**仅支持 H1**，无其他级别） |
| `L` | 无序列表 |
| `I2` | 缩进（`I` + 正整数） |
| `left` / `center` / `right` | 对齐方式（一段只能一种） |

- 普通段落不需要空参数的 `[P##内容]`，直接写文字即可
- 段落内容可包含 `T`、`F`、`Audio`、`Card`，但互相不可嵌套

### 2. 选择题 `[Choice#参数#...]`

```text
[Choice#fixed,multi#
* 正确选项
- 错误选项
]
```

- `* `（含空格）表示正确选项，`- ` 表示错误选项
- `multi` 多选题；`fixed` 固定顺序（省略则随机排列）
- `[Choice...` 必须从新一行开头开始，结尾 `]` 单独占一行
- 选项内只允许普通文字和 `[T#...#...]` 样式

### 3. 图片与画廊 `[Pic#ID/图片ID#]`

- 内容区必须为空，结尾是 `#]`
- 带遮罩：`[Pic#ID/图片ID,MID/遮罩ID#]`
- 相邻无换行的多张图片组成同一画廊；分行则为独立图片区块
- 不得编造图片 ID 和遮罩 ID

### 4. 独立公式 `[E##公式]`

```text
[E##E=mc^2]
```

- `[E##` 必须从新一行开头；结束 `]` 后不要同行追加文字

### 5. 答案分隔线 `---`

- 三个半角连字符，**单独占一行**，前后不可加空格或同行文字

---

## 四、转义规则

| 想显示 | 应输入 |
|---|---|
| `[` | `\[` |
| `]` | `\]` |

- 只转义作为普通文字显示的中括号，真正的语法外层括号不转义
- 内容区的 `#` 和英文逗号可直接写；**参数区**的 `#`、英文逗号和换行具有结构含义

---

## 五、嵌套与位置限制

| 容器 | 可放入的语法 |
|---|---|
| 普通段落 / `P` 段落 | `T`、`F`、`Audio`、`Card` |
| `Choice` 选项 | 仅 `T` |
| `T` / `F` / `Audio` / `Card` 内容 | 不放其他语法 |
| `Pic` | 内容必须为空 |
| `E` 公式 | 只写公式内容 |

`P`、`Choice`、`Pic`、独立 `E`、`---` 不可放进其他语法内部。

---

## 六、常见错误示例

| ❌ 错误 | ✅ 正确 |
|---|---|
| `[F#1挖空]`（少一个 `#`） | `[F#1#挖空]` |
| `题目：[Choice##...]`（块级前有文字） | 题目换行后再写 `[Choice##...]` |
| 多选无 `multi` | `[Choice#multi#...]` |
| `*正确选项`（无空格） | `* 正确选项` |
| `[T#B#区间 [0,1]]`（未转义） | `[T#B#区间 \[0,1\]]` |

---

## 七、输出前检查清单（12 项要点）

大小写规范 → 两个 `#` 及闭合 `]` → 块级从行首开始 → 选项前缀准确 → `multi`/`fixed` → 挖空编号为正整数 → 中括号转义 → 无违规嵌套 → 仅用 `H1` → 颜色 6 位小写十六进制 → 不编造 ID → 避免未列出参数。

## 八、完整示例

**问答卡片：**

```text
[P#H1#TCP 与 UDP 的区别]
TCP 和 UDP 分别是面向什么的传输层协议？
---
TCP 面向[F#1#字节流]，提供可靠传输；UDP 面向[F#2#报文]，不保证可靠交付。
```

**重点与挖空：**

```text
[P#H1#Cache 命中率]
[T#B#命中时间]越短、[T#B#命中率]越高，访存平均时间越短。
---
平均访存时间 = 命中时间 + 缺失率 × 缺失代价
```

**选择题：**

```text
[P#H1#选择题示例]
下列排序算法中，不稳定的是？
[Choice#
* 快速排序
- 归并排序
- 直接插入排序
- 冒泡排序
]
```

## 附：本仓库制卡约定

- **卡片文件**：一张卡片一个文本文件，存放于对应课程/章节目录（如
  `markji/数据结构/第5章-树与二叉树/xxx.txt`）
- **目录结构**：`markji/<课程>/<第N章-章节名>/`，与 `课程笔记/` 一一对应
- 卡片正文遵循上述语法规范；公式用 `[E##...]`，重点用 `[T#B#...]`，
  易错点用红字 `[T#!e53935#...]`，必背结论用黄底 `[T#!!fff59d#...]`
- 知识点覆盖为主，**不制作选择题卡**（`Choice` 语法保留在本文档中仅供语法参考）
- 上传图片/音频时使用真实资源 ID，不得编造

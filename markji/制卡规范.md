# 408 制卡规范（方法论 + 格式标准）

> 配套文档：`markji/墨墨记忆卡制卡指南.md`（Markji 官方语法速查）。
> 本文件规定**从课程笔记提取考点的思路**和**卡片的标准格式**。制卡前必须同时通读两份文档。

---

## 一、素材与覆盖策略

### 1.1 双源交叉覆盖

| 来源 | 作用 | 优先级 |
|---|---|---|
| `EX-考点总结/`（各章） | 制卡骨架。逐条扫描，每条编号必须"出卡或记跳过理由" | ★★★ 主源 |
| `课程笔记/*.md` | 补充源。提取 `==高亮==`、`**注意**`（含橙色注意块）、加粗结论句、表格条目 | ★★ 补漏 |
| 课程笔记中的表格 | 对比类考点集中地，每张表至少评估一次是否出对比卡 | ★★ 补漏 |
| 长推演例题、图片导图、复习提示 | **不出卡**，最多抽取其中可直接背诵的结论 | ✕ |

### 1.2 逐章制卡流程（每章一个批次）

1. 通读该章 EX 考点总结，按编号列出**考点清单**（一行一考点，标注来源行号与 ※ 级别）
2. 通读该章课程笔记，补充清单中遗漏的高亮/注意/表格考点
3. 逐条映射为卡片：一考点 → 一卡（多面考点拆成多卡）
4. 无法成卡的条目在清单中标注跳过理由（如"依赖图示""纯叙述"）
5. 按本规范的命名规则写入对应章节目录

### 1.3 覆盖率要求

- EX 总结中带 `※` 的条目、加粗结论句：**100% 成卡或记录跳过理由**
- 普通条目：能独立背诵的都成卡；上下文依赖过强的可合并为一张卡
- 课程笔记高亮/注意句：与 EX 重复的不重复出卡，笔记独有的补卡

## 二、考点形态 → 卡片类型映射

制卡时先判断考点形态，再套用对应模板（模板见第三节）。

| 类型代码 | 考点形态 | 卡片形式 | 典型例子 |
|---|---|---|---|
| `概念` | 名词定义、"XX 是什么" | 问答卡 | PCB 是进程存在的唯一标志 |
| `判据` | 结论性判据、"什么决定什么"、性质定理 | 问答卡或挖空卡 | 存储字长决定 MDR 位数 |
| `对比` | 容易混淆的两个/多个对象 | 对比卡（一维一卡） | TCP vs UDP 边界处理 |
| `数字` | 端口、字段长度、窗口范围、固定数值 | 挖空卡 | DNS 端口 53 |
| `公式` | 性能/时间/复杂度公式 | 挖空卡（含 `E` 公式） | 平均访存时间公式 |
| `流程` | 算法步骤、协议过程、处理流程 | 流程卡（整体问 + 关键步挖空） | 三次握手、中断处理流程 |
| `易错` | EX 中的"需要注意"、反例、易错正误对、难点辨析 | 易错卡（正误辨析问答，错处用红色标注） | PPP 信息段是 0~1500 而非 46~1500 |
| `场景` | "什么情况下选什么"应用判断 | 问答卡 | n 大且关键字可分解 → 基数排序 |

**一条考点含多种形态时拆卡**：如"调度算法"含思想 + 规则 + 优缺点 + 适用场景，可拆 2~3 张，每张正面只问一件事。

## 三、卡片格式模板（Markji 语法）

### 通用规则

- 一张卡片一个文本文件，文件内容 = 卡片正文（纯 Markji 语法），**不加任何头部元数据**
- 卡片正面第一行固定为类型标签：`[P#H1#类型·关键词]`（类型取第二节的类型代码），便于复习时识别考点性质
- 正面问题必须**不看答案可独立回答**；禁止"上述内容的缺点是什么"这类依赖性问法
- 答案放在 `---` 分隔线之后（挖空卡除外，挖空卡不需要 `---`）
- 公式一律用 `[E##...]` 独立公式或 LaTeX 行内写法；上下标用 `[T#up#]`/`[T#down#]`
- 关键数字、关键词在答案中用 `[F#1#]` 挖空强化
- 不使用图片/音频（无真实资源 ID）；不出现裸露未转义的 `[` `]`
- 合理利用强调语法（加粗、颜色、底色）突出记忆重点，使用约定见下节

### 强调语法使用规范（颜色 / 加粗 / 底色）

卡片不是纯文本搬运，重点必须"看得见"。约定如下（颜色均为 6 位小写十六进制）：

| 语法 | 用途 | 使用场景 | 频率约定 |
|---|---|---|---|
| `[T#B#...]` 加粗 | 关键词、判定词 | 答案中的核心名词、结论句主干 | 每卡 1~3 处，基本必用 |
| `[T#!e53935#...]` 红字 | 易错警示 | 易错卡中的错误说法、否定词（"并非""不能""≠"）、易混点 | 仅易错/对比卡使用，每卡 ≤2 处 |
| `[T#!!fff59d#...]` 黄底 | 必背核心 | 一张卡唯一需要刻进脑子的结论/判据 | 每卡 ≤1 处 |
| `[T#!1e88e5#...]` 蓝字 | 补充延伸 | 帮助理解的备注、口诀、来源提示（可省） | 可选 |

**克制原则**：强调是手段不是装饰——一张卡上任何一处强调都应该服务于"这块我会不会记错/记漏"；无信息量的整句标红、大面积铺底色一律禁止。

### 模板 1：问答卡（概念 / 判据）

```text
[P#H1#概念]
什么是树的带权路径长度（WPL）？
---
树中所有[F#1#叶结点]的带权路径长度之和。
[T#!!fff59d#只算叶子结点，非叶子结点的权值不计入。]
```

### 模板 2：挖空卡（数字 / 公式）

正面即挖空句，不设 `---`；一组关联数字放同一张卡，编号分组。

```text
[P#H1#数字]
GBN 的发送窗口满足 [F#1#1 ≤ W_T ≤ 2^n − 1]；SR 的发送/接收窗口满足 [F#2#W_T = W_R = 2^(n−1)]。
```

```text
[P#H1#公式]
平均访存时间 = [F#1#命中时间] + [F#1#缺失率] × [F#1#缺失代价]
```

### 模板 3：对比卡

一维一卡，问法点明对比维度，答案两端对举。

```text
[P#H1#对比]
在数据交付方式上，TCP 与 UDP 有何区别？
---
TCP：面向[F#1#字节流]，不保留报文边界；
UDP：[F#1#保留报文边界]，既不合并也不拆分。
```

### 模板 4：流程卡

整体问答为主，答案用编号步骤；关键步骤细节加挖空。步骤超过 5 步时可拆"整流程卡 + 单步细节卡"。

```text
[P#H1#流程]
简述中断处理的全过程（两大阶段）。
---
① 中断请求；② 中断响应（[F#1#判优]）；③ 中断处理：隐指令（关中断、保存断点、引出服务程序）→ [F#1#中断服务程序]。
```

### 模板 5：易错卡（易混淆 / 陷阱 / 难点辨析）

用于 EX 中的"需要注意"条目、反例、正误对。问法直接戳向"容易记错的那个点"，答案先给正确说法，再用红字点破错误根源。

```text
[P#H1#易错]
PPP 协议信息段的合法长度范围是多少？
---
[F#1#0~1500 字节]。
[T#!e53935#不是 46~1500！]PPP 是点对点链路而非总线形，无须 CSMA/CD，[T#B#没有最短帧的要求]，因此不存在 46 字节下限。
```

易混淆的成对概念优先用**对比卡**（模板 3）双向对照；单个易错结论用本模板。

## 四、文件命名与存放

- 路径：`markji/<课程>/<第N章-章节名>/<NN>-<考点短名>.txt`
- `NN` 为章内两位序号（01、02…），按考点在 EX 总结中出现的顺序编
- 考点短名：3~8 字中文，见名知义，如 `05-cache三映射对比.txt`
- 禁止在文件名中使用空格和正反斜杠

示例：

```text
markji/计算机网络/第3章-数据链路层/01-码元定义.txt
markji/计算机网络/第3章-数据链路层/02-最短帧长.txt
```

## 五、质量红线（出卡前自查）

1. **一卡一考点**：正面问一件事，答案不超过 5 行正文
2. **原子性**：长枚举（如宏内核缺点 5 条）拆卡，不整段塞入
3. **避免弱问答**：禁止"是/否""对/错"这种无法暴露思维过程的问题，改用挖空或正误辨析问答（易错卡）
4. **数字完整**：所有数值、单位、范围必须精确照录笔记，不得凭记忆改写
5. **可背诵性**：答案必须是"能背出来的句子"，不搬运需要上下文才能理解的段落
6. **图片依赖内容不出卡**；确有价值的只抽文字结论
7. **语法自查**：按《墨墨记忆卡制卡指南》第七节 12 项清单过一遍
8. **来源可溯**：每章批次结束后输出一张"本章制卡清单"（考点 → 卡片文件名 / 跳过理由），供抽查

## 六、预估规模与推进方式

- 以 EX 总结密度估计：全仓库约 **600~900 张**（DS 约 180、CO 约 220、OS 约 200、CN 约 200，实际以逐章扫描为准）
- 推进方式：按"章"为批次（每次一章），先出考点清单 → 确认或抽查 → 成卡 → 提交
- 顺序建议：计算机网络 → 操作系统 → 计算机组成原理 → 数据结构（章节少、条目典型，先跑通流程再攻大章）

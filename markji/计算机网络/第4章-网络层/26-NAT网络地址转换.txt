[P#H1#概念]
NAT 将[T#1#专用网络地址]转换为[T#2#公用地址]对外隐藏内部 IP 地址，使整个专用网只需一个全球 IP 地址就能与因特网连通。
---
解析：NAT 路由器至少有一个[F#3#有效的外部全球 IP 地址]，维护包含 WAN 端与 LAN 端散列值对的 NAT 转换表。
发送时将源 IP 地址和端口改为自己的全球 IP 地址和新端口；接收时将目的 IP 地址和端口改回本网对应主机。
[T#B#NAT 路由器工作在网络层和传输层——转发数据报时需要查看和转换传输层的端口号]；[T#!e53935#普通路由器转发 IP 数据报时不改变源 IP 和目的 IP，NAT 路由器一定要更换 IP 地址]。
